Method

Revised Algorithm 1 · RPM common-intersection tiering

Revised Algorithm 1 RPM bootstrap common-intersection tiering

Inputs: task-by-model outcome matrix Y ∈ ℝN×J; subsample size m (default max{2, ⌊N0.9⌋}); replicate count B (default 5000); central rank-mass level 1 − α; RNG seed.

Output: an ordered partition 𝒯 of the observed leaderboard into tiers.

1: (Bootstrap rank mass.) For b = 1,…,B, sample m task rows with replacement and compute every model's bootstrap mean. A g-way score tie occupying ranks a,…,a+g−1 contributes mass 1/g to each tied model at each occupied rank.
2: (RPM and rank CDFs.) Set R̂jk to model j's average bootstrap mass at rank k, and F̂j(k) ← ∑r≤k R̂jr.
3: (Central rank-mass intervals.) For each model j, set Lj ← min{k : F̂j(k) ≥ α/2} and Uj ← min{k : F̂j(k) ≥ 1 − α/2}.
4: (Observed order.) Let π(1),…,π(J) be the models sorted by descending observed score.†
5: Initialize T ← {π(1)}, ℓ ← Lπ(1), u ← Uπ(1), and 𝒯 ← [ ].
6: for t = 2,…,J do
7: ℓ′ ← max(ℓ, Lπ(t)); u′ ← min(u, Uπ(t)).
8: if ℓ′ ≤ u′ then ▷ every member still shares a plausible rank
9: T ← T ∪ {π(t)}; ℓ ← ℓ′; u ← u′.
10: else ▷ empty common intersection: close the current tier
11: Append T to 𝒯; T ← {π(t)}; ℓ ← Lπ(t); u ← Uπ(t).
12: end if
13: end for
14: Append T to 𝒯.
15: Return 𝒯 in observed-score order.

† Models with equal unrounded observed scores (absolute tolerance 10−12) stay together: intersect their rank-mass intervals and add the entire tied set at once. If adding it would empty the current tier's common intersection, start the next tier before the tied set; if the tied models themselves share no rank, flag the incompatibility rather than splitting them.

Revision relative to the theory note. Step 8 requires one rank shared by every interval in a tier. It replaces connected-component merging of pairwise overlaps, preventing a chain such as [1,2], [2,3], [3,4] from collapsing into one tier. The first two intervals form a tier; the third starts the next tier.
