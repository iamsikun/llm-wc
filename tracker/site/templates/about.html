The paper

Ranking noisy benchmark scores tends to inflate the scores of top-ranked models and deflate those near the bottom. The paper develops an {% filter tex %}m{% endfilter %}-out-of-{% filter tex %}N{% endfilter %} bootstrap that estimates and corrects for this rank-induced bias at every leaderboard position, reducing it to lower order under exact population tiers, and reports the rank uncertainty that remains as RULER: a rank probability matrix, rank-mass intervals, and tiers. It audits {{ headline.n_settings }} benchmarks from {{ headline.families }} benchmark families and validates the correction with sample splitting and a calibrated simulation.

This site

The tracker checks each leaderboard's source {{ site.update_cadence }} and runs the same analysis on every new snapshot. Each leaderboard page lists its snapshots by source date and links each one to its upstream revision. For the snapshots analyzed in the paper, every build checks the numbers against the paper's committed results.

Everything is reproducible from the repository: the paper's experiments, the tracker's snapshots (with SHA-256 checksums and upstream revisions), and the code that builds these pages.
